# Plan — what to build next, and why

*Written 2026-08-05, after 11 freezes and 1,290 real-data experiments.*

---

## 1. Where this actually stands

The project set out to answer one question: **does trading AI/technology stocks
beat simply owning the leading ones?** After four real-data studies the
provisional answer is **no, with one exception**, and the exception is not an
indicator.

| | |
|---|---|
| Real experiments run | 1,290 (freeze v3: 624, v4: 666) |
| Robust candidates | **2** — the same strategy at two settings |
| Rejected | 71 |
| Inconclusive | 56 |
| Data-quality gate | PASS WITH LIMITATIONS |
| Holdout openings | **3** |

The survivor is `BetaHedgedBasket` — own the shortlist, short QQQ against it at
trailing beta. Holdout Sharpe 1.62, worst drawdown −33.8%, evidence Tier B.

**Five independent lines converged on the same structural finding:**

1. v3 — 208 long-only variants all correlated 0.7–0.9 with the index. That was
   the study's own constraint, not a fact about technology stocks.
2. v4 — the only construction ever to clear the bar was also the only one whose
   correlation to the index was near zero.
3. v6 — `TurnOfMonth` was designed to be uncorrelated and came in at +0.53,
   because its exposure was still long the market whenever it was on.
4. v8/v9 — 92 chart-indicator variants lost to equal-weighting eight AI
   megacaps monthly. Cutting turnover 3.2× left Sharpe unchanged, so the churn
   was pure noise and removing it changed nothing.
5. v11 — hedging the market out of the chart signals removed ~25 points of
   drawdown **and more Sharpe than it saved**. Once the market is subtracted,
   nothing is left.

A long-only rule on technology is the index bet minus the fees. That is not a
tuning failure, and eleven freezes of iteration have not moved it.

### What this implies for the plan

**Further backtesting has sharply diminishing returns.** The holdout has been
opened three times, so every additional backtest produces development evidence
by definition. Adding a twelfth indicator would cost a freeze, a re-run, and
would answer a question already answered five ways.

The three things that *would* change what we know are: forward evidence,
de-risking the one live claim, and removing things that actively mislead.

## 2. Current capabilities — honest inventory

### What works well

- **Bias controls.** Next-open execution enforced structurally; point-in-time
  universe with IPO seasoning and delisting; publication-date-gated
  fundamentals; a hash-chained holdout lock opened exactly once per study.
  177 tests, many of them adversarial rather than confirmatory.
- **The research freeze.** 34 code modules plus every config fingerprinted;
  real-mode entry points refuse to start on drift. It has caught real problems
  (AUD-016) and forced honest version bumps (v6→v7 when a control arm silently
  did not run).
- **Multiple-testing discipline.** Deflated Sharpe over the full trial battery,
  failures included. The new Narrow-bets page extends this per-target.
- **Cost realism.** Four scenarios, commission + half-spread + slippage +
  √participation impact + borrow.
- **Provenance.** Nothing is silently substituted. Missing data produces a
  refusal, not a fallback — this has fired correctly many times.

### What is weak

| Weakness | Consequence |
|---|---|
| **Flat borrow assumption** | The *only* surviving result is a short-side strategy priced with a constant borrow rate nobody has verified. This is the single largest unquantified risk in the project. |
| **Tier B, not A** | Revised macro series (not real-time vintages), 33/39 delisted names with usable history. |
| **No factor attribution** | We cannot say whether the hedged residual is genuine selection or an unpriced size/momentum tilt. |
| **No forward record** | Zero out-of-sample evidence exists. Not "some" — zero. |
| **Verdict layer admits ~3% noise** (AUD-010) | Known, documented, unfixed. |
| **56 inconclusive variants** | Neither retired nor defended; they sit in the record inflating the trial count. |

### Website — design state

Seven tabs: Overview · The data · Strategies · Results · Chart it · Narrow
bets · Method & trust. That is one more than the six the tab consolidation
settled on, and worth watching — the last complaint was that nine was too many.

**Live defect:** six pages remain committed and publicly served that
`build_site` no longer generates and no nav links to — `audit.html`,
`compare.html`, `experiments.html`, `ideas.html`, `portfolio.html`,
`roadmap.html`. They are stale, carry the old nine-tab navigation, and are
reachable by URL.

**Structural gap:** the site documents research thoroughly and answers
"what would I actually do?" nowhere. There is no view of what the surviving
strategy says to hold *today*.

**Build performance — found and fixed while writing this plan.** A full site
build had reached **118 seconds** and was growing with every study. Two causes:

1. `assistant_review` compared every pair of recorded strategies with a
   `concat` + `corr` per pair — ~500,000 Python-level pandas calls at the
   current 999-record cohort, and *quadratic*, so each study made it worse. It
   was 106 of the 118 seconds. Replaced with one aligned frame and a single
   vectorised `.corr()`: **106s → 25s, byte-identical output** (143
   suggestions, same 123/19/1 breakdown).
2. The 40 MB registry was re-parsed for every strategy page. Now cached per
   process, handing out copies so a mutating caller cannot poison it.

Build is now **46 seconds**. This matters beyond convenience: a publish step
slow enough to skip is one that *gets* skipped, and a stale published site is
exactly the failure this project keeps having.

**Remaining growth risk, unfixed:** the synthetic registry is 7,805 records and
40 MB; curves number 7,818 files. Both grow by ~1,000 per study with no
retention policy. The next bottleneck is the 999 curve reads (~25s). At the
current rate this needs a cohort-scoped read or a retention rule within a few
more freezes.

## 3. The plan

Three tracks. Track A is the only one that produces new evidence; B makes the
one live claim trustworthy; C removes things that mislead.

### Track A — Forward evidence (the only clean evidence left)

**A1. Paper-trading harness.** *(largest item; nothing else substitutes)*

The holdout is spent. The only remaining source of genuinely out-of-sample
evidence is running the frozen strategy forward and recording what it did,
before knowing the outcome.

Needs:
- a daily job that loads the current store, rebuilds `BetaHedgedBasket`'s
  weights, and appends them to an **append-only, timestamped signal log**
  written *before* the session it applies to;
- reconciliation that compares realised returns against the frozen prediction
  and accumulates a live track record;
- a hard rule that the log is never regenerated retroactively — a rebuilt
  forward record is a backtest wearing a costume.

`docs/prospective_testing_protocol.md` specifies the protocol; the harness does
not exist. **This is the highest-value build in the project.**

**A2. "Today" page on the site.** *(depends on A1)*

One page: what the surviving strategy holds now, what changed since the last
rebalance, the live out-of-sample record so far, and how long it must run
before the number means anything. Framed as paper trading throughout — the
decision brief is structurally incapable of recommending live trading and this
page must not become a loophole.

### Track B — Make the one survivor trustworthy

**B1. Per-name borrow costs.** *(roadmap rank 2; highest-value data work)*

The entire hedged result assumes a flat borrow rate. QQQ is cheap and deep so
the error is probably small, but "probably" is not a measurement. Until this is
priced, the project's only positive finding rests on an unverified assumption.

**B2. Factor-exposure attribution.** *(roadmap rank 10, underrated)*

Regress the hedged residual on size, momentum and quality proxies. If the
residual is a momentum tilt in disguise, that is worth knowing before paper
trading it for a year. Cheap — needs no new data.

**B3. Capacity at real size.** Capacity analysis exists; it has not been run
against the survivor specifically with the participation cap binding.

### Track C — Pay down what actively misleads

**C1. Delete the six orphaned pages.** Stale research served publicly with no
navigation. Cheapest win here.

**C2. Retire or defend the 56 inconclusive variants.** *(roadmap rank 3)* Each
one either gets a reason to remain in the battery or is deprecated with a
stated cause. They currently inflate the trial count without contributing.

**C3. AUD-010** — the verdict layer alone admits ~3% of pure-noise strategies.
Documented and open. Either tighten it or state the residual false-positive
rate on the Results page where verdicts are read.

**C4. Watch the tab count.** Seven now. If an eighth is proposed, something
merges first.

### Explicitly NOT next

- **More indicators.** 0 for 92, and v11 explained why.
- **More freezes without real runs.** v5 through v11 have never touched real
  prices. Freeze churn is not progress.
- **Per-cluster parameter tuning.** The Narrow-bets page exists to show why.

## 4. Sequencing

| Order | Item | Why here |
|---|---|---|
| 1 | Run the real study under v11 | ~100 variants have never seen real prices; everything else is uncalibrated until they do |
| 2 | C1 — delete orphaned pages | minutes, and it is publicly wrong now |
| 3 | B2 — factor attribution | cheap, no new data, and could invalidate the survivor before a year is spent paper-trading it |
| 4 | B1 — per-name borrow | the survivor's largest unquantified risk |
| 5 | A1 — paper-trading harness | the only new evidence available; start the clock as early as possible |
| 6 | A2 — Today page | needs A1 to have something to show |
| 7 | C2, C3 | governance debt; real but not blocking |

B2 sits before A1 deliberately: if the hedged residual turns out to be an
unpriced factor tilt, that is better discovered in an afternoon than after
twelve months of forward recording.

---

## 5. The decision this plan does not make

If B1 and B2 both come back clean and the v11 real study adds nothing, the
honest position is that this study has produced **one** finding worth acting
on, and the only way to test it further is to run it forward for a year.

"Own a diversified AI basket, rebalance monthly, do not trade it" remains a
defensible conclusion that four real studies now support. Reaching it is a
result, not a failure — and it is what the evidence currently says.
